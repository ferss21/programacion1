# Semana 12: herencia y polimorfismo

## Objetivo

Reutilizar una clase base y cambiar el comportamiento de sus métodos cuando sea necesario.

## Temas

Herencia simple, `super()` y sobrescritura de métodos.

## Ejecutar y practicar

Ejecutar los ejemplos con Python 3. Mantener las clases pequeñas y fáciles de explicar.
