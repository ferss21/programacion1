# Actividad de clase: tipos de atención

Cree una clase base `Ticket` y dos subclases, por ejemplo `TicketSoporte` y `TicketUrgente`. Sobrescriba un método de resumen para que cada tipo muestre información adicional. Recorra una lista mixta y llame al mismo método en todos los objetos.

Identifique dónde se aplica `super()` y dónde se aplica el polimorfismo.
