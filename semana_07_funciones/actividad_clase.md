# Actividad de clase: reporte de productos

La coordinación necesita procesar las calificaciones de varios grupos sin repetir lógica. Construya un programa de consola para registrar estudiantes y notas, y presentar un resumen que incluya promedio y cantidad de aprobados.

Separe el trabajo en funciones para solicitar y validar datos, calcular resultados y mostrar el reporte. Pase la información mediante parámetros y valores de retorno; pruebe también un grupo vacío y una búsqueda sin coincidencias. Puede usar [la práctica guiada](practica_especial.py) como archivo de trabajo.
