# Semana 4: decisiones

## Objetivo

Elegir acciones distintas según una condición.

## Temas

Booleanos, operadores de comparación y lógicos, `if`, `elif`, `else` e indentación.

## Ejecutar y practicar

Ejecutar cualquier `ejemplo_*.py` con Python 3 y completar `practica.py` cambiando condiciones y datos de prueba.

- [Actividad de clase](actividad_clase.md): clasificación de solicitudes.
- [Tarea evaluada](tarea_evaluada.md): admisión a un curso.
