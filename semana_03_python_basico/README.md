# Semana 3: introducción a Python

## Objetivo

Escribir los primeros programas y trabajar con datos sencillos.

## Temas

- `print`, variables y tipos.
- `input`, conversiones y operadores.
- Cálculos con números y texto.

## Ejecutar

Desde esta carpeta, por ejemplo: `python ejemplo_01.py`. La práctica solicita datos desde la consola.

## Práctica

Completar la práctica de datos del estudiante y el cálculo de compra. En esta semana solo se presenta Git para clonar el material y consultar `git status`.
