# Proyecto final: sistema de gestión de tickets

Desarrolle un sistema de consola que permita crear, mostrar, buscar, actualizar, cambiar el estado y eliminar tickets. La información debe guardarse en SQLite.

Cada ticket incluirá id, título, descripción, categoría, prioridad y estado. Los estados sugeridos son Abierto, En proceso y Cerrado; las prioridades son Baja, Media y Alta.

El programa debe mostrar de forma clara el uso de variables, condicionales, ciclos, colecciones, funciones, módulos, clases y SQLite. Puede organizarlo de otra manera si puede explicar su decisión. No se requiere interfaz gráfica ni aplicación web.

La carpeta `ejemplo_estructura` muestra cómo separar las partes principales, pero no constituye una solución completa.

> Durante la presentación, el estudiante deberá explicar el funcionamiento general del sistema, identificar las principales partes de su código y realizar cambios sencillos solicitados por el docente.
