# Semana 8: módulos y Git

## Objetivo

Separar código en módulos y registrar avances con el flujo básico de Git.

## Temas

`import`, módulos, paquetes, espacios de nombres y alias. En Git: repositorio, cambio, commit, remoto e historial.

## Ejecutar y practicar

Ejecutar `python main.py`. Practicar `git status`, `git add .`, `git commit`, `git push` y `git pull`.
