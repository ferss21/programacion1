# Tarea evaluada: mini sistema modular

Construya un programa de consola dividido en al menos tres módulos propios. Debe registrar datos de tickets o compras, calcular un resumen y mostrar mensajes de salida sin duplicar lógica.

Entregue los `.py`, un `README.md` breve con la responsabilidad de cada módulo y evidencia de `git status`, `git add`, `git commit` y `git log`.

Evaluación: separación de responsabilidades 35% · imports y ejecución 25% · flujo funcional 20% · evidencia Git y documentación 20%.
