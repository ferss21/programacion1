# Actividad de clase: separar un programa en módulos

Un equipo de soporte necesita registrar solicitudes y resumirlas por prioridad. Organice el programa en módulos propios: uno para cálculos o validaciones, otro para mensajes y un archivo principal que coordine las operaciones.

Compruebe que los imports funcionen y que el reporte coincida con los registros ingresados. Use `git status`, prepare los archivos, cree un commit descriptivo y revise el historial. La [práctica guiada](practica_especial.py) contiene el reto completo.
