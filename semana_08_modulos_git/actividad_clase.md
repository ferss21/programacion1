# Actividad de clase: separar un programa en módulos

Tome un programa de compras y sepárelo en tres partes: `calculos.py` para operaciones, `mensajes.py` para salidas y `main.py` para coordinar el flujo. Pruebe los imports y registre el avance con un commit descriptivo.

Muestre `git status`, el cambio preparado y el historial del commit.
