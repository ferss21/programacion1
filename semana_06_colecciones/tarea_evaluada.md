# Tarea evaluada: inventario en memoria

Desarrolle un inventario usando una lista de diccionarios. Cada producto tendrá código, nombre, precio, cantidad y categoría. El programa debe permitir agregar, buscar, modificar existencias, eliminar y mostrar un reporte del inventario.

Use strings para normalizar códigos y nombres, una tupla para las categorías válidas y diccionarios para representar productos. No use clases ni archivos todavía.

Evaluación: estructura de datos 25% · operaciones 35% · búsqueda y validaciones 20% · reporte y documentación 20%.
