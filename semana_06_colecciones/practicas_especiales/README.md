# Prácticas especiales — Semana 6

Cinco ejercicios para resolver en clase usando los temas vistos hasta la semana 6: variables, decisiones, ciclos y colecciones.

Abra cada archivo y escriba ahí su solución. No se incluyen resultados ni código resuelto. Evite usar funciones y temas de semanas posteriores.

1. [Notas del grupo](actividad_01_notas_grupo.py)
2. [Puesto de comida](actividad_02_puesto_comida.py)
3. [Biblioteca del aula](actividad_03_biblioteca_aula.py)
4. [Presupuesto para una excursión](actividad_04_excursion.py)
5. [Encuesta de lectura](actividad_05_encuesta_lectura.py)

## Criterios de resultados

- **Notas del grupo:** registra estudiantes, clasifica las notas y presenta un resumen correcto; la búsqueda funciona aunque no haya coincidencias.
- **Puesto de comida:** registra pedidos válidos, calcula los importes y presenta un total coherente con las ventas.
- **Biblioteca del aula:** permite consultar y actualizar el estado de los libros, y evita préstamos o devoluciones que no correspondan.
- **Presupuesto para una excursión:** registra participantes y gastos, calcula el saldo y presenta cuánto corresponde aportar a cada persona.
- **Encuesta de lectura:** cuenta las preferencias correctamente e identifica el género más elegido, incluidos los empates.

En todas las prácticas se espera que el programa valide las entradas indicadas, use colecciones adecuadas y muestre la información de forma clara.
