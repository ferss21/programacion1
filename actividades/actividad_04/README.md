# Actividad 4: tickets en un archivo

## Consigna

Cree un registro básico de tickets almacenado en un archivo de texto. El programa debe registrar, guardar, leer y mostrar tickets.

## Instrucciones

- Use funciones y `with open`.
- Guarde por lo menos título, prioridad y estado.
- No use SQLite.

## Entrega

Entregue el programa `.py` y un archivo de texto con datos de prueba.

> El estudiante deberá estar preparado para explicar el funcionamiento del código desarrollado y realizar ajustes sencillos solicitados por el docente durante la revisión.
