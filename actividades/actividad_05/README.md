# Actividad 5: clase Ticket

## Consigna

Cree un programa con una clase `Ticket`. Cada ticket debe tener número, título, descripción, prioridad y estado.

## Instrucciones

- Incluya métodos sencillos para mostrar y actualizar información.
- Cree varios objetos y guárdelos en una lista.
- No use base de datos.

## Entrega

Entregue el archivo `.py` con la clase y una demostración de su uso.

> El estudiante deberá estar preparado para explicar el funcionamiento del código desarrollado y realizar ajustes sencillos solicitados por el docente durante la revisión.
