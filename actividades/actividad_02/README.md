# Actividad 2: registro de estudiantes

## Consigna

Cree un registro que permita agregar estudiantes, mostrarlos, buscarlos por nombre o identificación y consultar su nota.

## Instrucciones

- Use una lista de diccionarios, ciclos y condicionales.
- Incluya un menú que se repita hasta elegir salir.
- No use clases.

## Entrega

Entregue el archivo `.py` con el programa y algunos datos de prueba.

> El estudiante deberá estar preparado para explicar el funcionamiento del código desarrollado y realizar ajustes sencillos solicitados por el docente durante la revisión.
