# Actividad 2: decisiones y ciclos

**Semana:** 5 · **Ponderación:** 15%

## Consigna

Cree un programa que procese varias compras o notas y muestre un resultado para cada dato. Debe incluir decisiones y un menú o repetición que permita procesar más de un caso.

## Instrucciones

- Use `if`, `elif`, `else`, `for` o `while`.
- Incluya al menos un contador o acumulador.
- Use datos de prueba que cubran más de una condición.
- No use listas de diccionarios ni clases.

## Entrega

Entregue un archivo `.py` que se pueda ejecutar desde la consola y explique con comentarios breves qué hace cada parte principal.

> El estudiante deberá estar preparado para explicar el funcionamiento del código desarrollado y realizar ajustes sencillos solicitados por el docente durante la revisión.
