# Actividad 6: CRUD con SQLite

**Semana:** 13 · **Ponderación:** 15%

## Consigna

Cree un CRUD pequeño de tickets con Python y SQLite. Debe permitir crear, consultar, actualizar y eliminar registros.

## Instrucciones

- Use el módulo `sqlite3` incluido con Python.
- Mantenga las instrucciones SQL visibles en el código.
- Use consultas con parámetros `?` para los datos ingresados.
- Mantenga el programa pequeño y centrado en las cuatro operaciones.

## Entrega

Entregue los archivos `.py` necesarios. La base de datos puede crearse al ejecutar el programa.

> El estudiante deberá estar preparado para explicar el funcionamiento del código desarrollado y realizar ajustes sencillos solicitados por el docente durante la revisión.
