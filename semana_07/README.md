# Semana 7: módulos y Git

`main.py` importa funciones de `calculos.py` y `mensajes.py`. Al importar un módulo se utiliza su propio espacio de nombres; por eso se escribe, por ejemplo, `calculos.sumar()`.

Comandos para practicar esta semana:

```bash
git status
git add .
git commit -m "semana 7"
git push
git pull
```
