# Semana 10: programación funcional introductoria

## Objetivo

Conocer dos formas pequeñas de controlar la ejecución de funciones.

## Temas

Generadores, `yield` y decoradores.

## Ejecutar y practicar

Ejecutar los ejemplos con Python 3 y completar `practica.py` cambiando la lista de notas.

## Actividades

- Actividades sencillas para repasar las semanas 1 a 10. En cada archivo están la consigna y los puntos que se deben practicar; puedes elegir los datos y la forma de resolverlas:
  1. [Mis calificaciones (resuelta)](actividades_integradoras/actividad_01_calificaciones.py): datos, decisiones, ciclos, colecciones y funciones.
  2. [Una compra sencilla](actividades_integradoras/actividad_02_cafeteria.py): entrada de datos, conversiones, cálculos y ciclos.
  3. [Mi lista de cosas](actividades_integradoras/actividad_03_inventario.py): colecciones, métodos y archivos de texto.
  4. [Una recomendación para ti](actividades_integradoras/actividad_04_biblioteca.py): funciones, módulos y recursividad.
  5. [Mostrar solo lo que me interesa](actividades_integradoras/actividad_05_solicitudes.py): generadores, decoradores y repaso de Git.
- [Práctica guiada](practica_especial.py): reporte filtrado con generadores y decorador.
- [Tarea evaluada](tarea_evaluada.md): reporte diferido y auditoría.
