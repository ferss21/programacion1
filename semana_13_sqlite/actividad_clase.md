# Actividad de clase: consultas con SQLite

Regístrese en SQLite Cloud y cree una base para el curso. Conecte Python a esa base y desarrolle un menú para registrar, listar, buscar, actualizar y eliminar solicitudes; los datos deben seguir disponibles al cerrar y volver a ejecutar el programa.

Use `sqlitecloud`, consultas parametrizadas con `?` y los tres valores de conexión guardados en `.env`. Compruebe cuántos registros modifica cada operación y pruebe un identificador inexistente. Siga la [práctica guiada](practica_sqlite_cloud.py) y las instrucciones del README.
