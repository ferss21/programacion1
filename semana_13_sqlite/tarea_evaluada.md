# Tarea evaluada: CRUD de tickets

Desarrolle un CRUD de consola con SQLite que permita crear, listar, buscar, actualizar el estado y eliminar tickets. Debe incluir validación de entradas, consultas parametrizadas y funciones separadas para las operaciones de base de datos.

La base debe conservar la información entre ejecuciones. Entregue los archivos `.py`, instrucciones de ejecución y cuatro casos de prueba, incluyendo un id inexistente.

Evaluación: esquema y conexión 20% · CRUD 40% · seguridad y validación 20% · documentación y pruebas 20%.
