# Programación I

Repositorio de la materia Programación I de la Universidad del Istmo. Durante el curso trabajaremos con Python desde los primeros programas hasta un pequeño sistema con SQLite.

Las carpetas `semana_01` a `semana_13` contienen ejemplos y prácticas. En `actividades` están las consignas evaluadas y en `proyecto_final` la guía del trabajo final.

## Requisitos

- Python 3
- Git
- Un editor de código

## Comandos básicos de Git

```bash
git clone https://github.com/ferss21/programacion1.git
git status
git add .
git commit -m "practica semana 2"
git push
git pull
```
