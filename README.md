# Programación I

Repositorio de la materia Programación I. El curso comienza con análisis de problemas y algoritmos; Python se introduce en la semana 3 y se aplica progresivamente hasta un sistema de atención de solicitudes conectado a SQLite Cloud.

## Requisitos

- Python 3
- Git
- Un editor de código

## Semanas

| Semana | Tema |
|---:|---|
| 1 | Pensamiento lógico y análisis de problemas |
| 2 | Algoritmos y pseudocódigo |
| 3 | Introducción a Python |
| 4 | Decisiones |
| 5 | Ciclos |
| 6 | Colecciones |
| 7 | Funciones |
| 8 | Módulos y Git |
| 9 | Archivos y métodos |
| 10 | Programación funcional introductoria |
| 11 | Orientación a objetos |
| 12 | Herencia y polimorfismo |
| 13 | Bases de datos: SQLite Cloud |
| 14 | Integración del proyecto final |
| 15 | Proyecto final |
| 16 | Carga de notas |

Las semanas 1, 2 y 14 se entregan por separado porque contienen material escrito de apoyo y no ejemplos de código. Este repositorio conserva las carpetas de semanas que ya existen, sin agregar nuevas semanas. La integración del proyecto final se trabaja con la guía de [proyecto_final](proyecto_final/README.md).

## Actividades y evaluaciones

Cada carpeta de semana contiene un `actividad_clase.md` para trabajo guiado y un `tarea_evaluada.md` con consigna, entregables y rúbrica. La guía de [proyecto_final](proyecto_final/README.md) contiene el cierre integrador.

La ponderación global se asigna según la planificación del curso; las rúbricas quedan documentadas junto a cada tarea para que la evaluación sea consistente.

## Git

En la semana 3 se practican únicamente la descarga del repositorio y `git status`:

```bash
git clone https://github.com/ferss21/programacion1.git
cd programacion1
git status
```

El flujo básico se trabaja formalmente en la semana 8:

```bash
git status
git add .
git commit -m "avance semana 8"
git push
git pull
```

No se requieren ramas ni comandos avanzados para este curso.
