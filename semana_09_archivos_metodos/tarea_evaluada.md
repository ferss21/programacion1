# Tarea evaluada: registro persistente de tickets

Desarrolle un programa modular que almacene tickets en un archivo de texto. Debe permitir crear, listar, buscar por código, actualizar el estado y eliminar un ticket.

Cada línea debe guardar código, título, prioridad y estado. El programa debe reconstruir los registros al iniciar, manejar líneas vacías y conservar los datos después de cerrar.

No use SQLite. Entregue los `.py`, un archivo de datos de prueba y evidencia de Git.

Evaluación: lectura y escritura 30% · operaciones 30% · uso de métodos 20% · documentación, pruebas y Git 20%.
