# Semana 9: archivos y métodos

## Objetivo

Guardar información sencilla en archivos y usar métodos frecuentes de strings, listas y diccionarios.

## Temas

Lectura y escritura de archivos, `with open`, persistencia sencilla y métodos de `str`, `list` y `dict`.

## Ejecutar y practicar

Ejecutar los ejemplos con Python 3 y comprobar que los datos sobreviven al cierre del programa.

- [Actividad de clase](actividad_clase.md): persistencia de tickets.
- [Práctica guiada](practica_especial.py): solicitudes persistentes en un archivo.
- [Tarea evaluada](tarea_evaluada.md): registro persistente de tickets.
